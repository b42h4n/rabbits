# Rabbits

A meme "virus" for Linux. You run the script, and the screen quickly fills up with windows featuring bunnies, all while a looped piece of music plays.

> **Note:** This is not a serious project. It was created as a result of a bet with a friend who said I couldn't build a Linux alternative to "Зайцы, почему тут зайцы". Expect bugs

Esc - close program
